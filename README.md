# 文庫組版シミュレーター（bunko-tools）

Web小説の原稿を、A6文庫本（縦組み・右綴じ）として組版し、PDFに保存できるブラウザツールです。
サーバー処理はなく、原稿や画像はすべて利用者のブラウザ内で処理・保存されます。

**▶ https://crystar-studio.github.io/bunko-tools/**

## 使い方

1. 本文欄に原稿を貼り付ける
2. 版面・書体・体裁を設定する
3. 見開きで確認し、「PDFで保存」

### PDF保存の設定

「PDFで保存」を押すと印刷ダイアログが開きます。次の設定で、A6・1ページ1面のPDFになります。

| 項目 | 設定 |
|---|---|
| 送信先 | PDFに保存 |
| 用紙サイズ | 自動でA6（105×148mm）になります |
| 余白 | なし |
| 倍率 | 100%（デフォルト） |
| 背景のグラフィック | オン（表紙の色・画像を出すため） |

Chrome / Edge を推奨します。

## 原稿の記法

| 書きたいもの | 書き方 | 備考 |
|---|---|---|
| ルビ | `｜漢字《かんじ》` / `漢字《かんじ》` | 小説家になろう・カクヨム互換 |
| 傍点 | `《《強調》》` | |
| "強調" | `"ルイ"` | 傍点・〝ノノカギ〟などを体裁パネルで選択 |
| 章見出し | 行頭に `# ` | 章ごとの改ページ・柱に使われます |
| 改ページ | `［改ページ］` または `[newpage]` | |
| 挿絵 | `［挿絵：画像名］` | 1ページ全面、隠しノンブル |
| 縦中横 | 自動 | 2桁の数字、`!?` などの2文字 |
| タイトルの改行 | タイトル欄に `｜` | 表紙・扉のみ。長い場合は自動縮小 |

## 主な機能

- **版面**：字詰め×行数（プリセット：42字×17行ほか）、天・地・ノド・小口の余白をmmで指定。本文サイズと行送りは自動算出
- **書体**：Noto Serif JP / しっぽり明朝 / Zen Old Mincho / BIZ UDP明朝 / Klee One
- **体裁**：表紙（イラスト・帯）、口絵（見開き）、扉、ノンブル、柱、奥付、16ページ単位の折揃え
- **組版**：禁則処理、段落をまたぐページ送り、見開き／単ページ表示
- **閲覧**：←→キー・タップ・スワイプでページ送り（右綴じなので左へ進みます）

## 自作小説を電子書籍として公開する

`index.html` を複製し、冒頭の2つのタグを書き換えると、編集パネルのない閲覧専用ページになります。

```html
<script id="book-config" type="application/json">
{ "mode": "reader", "title": "作品名", "author": "著者名", "chars": 42, "lines": 17,
  "images": { "cover": "img/cover.jpg", "illust1": "img/illust1.jpg" }, "coverImg": "cover" }
</script>
<script id="manuscript" type="text/plain">
ここに原稿を貼る
</script>
```

- 設定できる項目は、ソース中の `DEF` オブジェクトのキーと同じです。
- 画像は data URI ではなく、リポジトリ内の相対パスで指定すると軽くなります。
- 原稿中に `</script>` という文字列は書けません。

## 注意事項

- ページ分割はブラウザの実際の描画を測って決めているため、ブラウザやOS、フォントの読み込み状況によってページ数が数ページ前後することがあります。入稿用のPDFは、同じ環境でまとめて書き出してください。
- ルビが親文字より長い場合の処理や、ぶら下げ組み（Safari以外）は、DTPソフトほど厳密ではありません。
- 保存はブラウザの localStorage を使います（おおむね5MBまで）。画像を多く入れると保存しきれない場合があり、その場合はページを開いている間だけ有効です。
- 印刷所への入稿データとして使う場合は、塗り足し・トンボ・フォントの埋め込み条件など、印刷所の入稿規定を必ず確認してください。

## 公開方法（GitHub Pages）

1. このリポジトリを GitHub に push
2. Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` に設定
3. https://crystar-studio.github.io/bunko-tools/ で公開されます

ビルド工程はありません。`.nojekyll` を置いているので、ファイルはそのまま配信されます。
